# IPL Score Predictor 🏏

A Machine Learning-based web application that predicts the first innings score of an IPL match based on current match conditions.

## Features

* Predict IPL first innings score
* User-friendly web interface
* Machine Learning model integration
* Flask web application
* Real-time prediction

## Technologies Used

* Python
* Flask
* Pandas
* NumPy
* Scikit-Learn
* HTML/CSS
